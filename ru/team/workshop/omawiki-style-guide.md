# Руководство по оформлению вики OpenMandriva
> Сначала ознакомьтесь с [общим руководством по оформлению вики](/en/team/workshop/wiki-style-guide)
{.is-danger}

## Особые правила вики OpenMandriva

> Эта страница находится в разработке и будет постепенно обновляться по мере появления новых рекомендаций.
{.is-info}


### Образы
Снимки экрана и другие образы, размещаемые на страницах вики, необходимо загружать **только** в папку `/images`.
Именно для этого она и предназначена.

Имена файлов образов не должны содержать:
- Пробелы (вместо них используйте дефисы)
- Символы подчёркивания (вместо них используйте дефисы)
- Точки (зарезервированы для расширений файлов)
- Небезопасные символы URL (например, знаки препинания, кавычки, математические символы и т. д.)

По возможности присваивайте файлам изображений осмысленные имена, отражающие содержание страницы или то, что изображено на них.

### Пути
Пути должны содержать только строчные буквы. Для разделения слов используйте дефисы.
Знаки препинания не допускаются, за исключением дефисов и/или символов подчёркивания.
-- Примечание: хотя использование символов подчёркивания *технически* допускается, стандарт вики OpenMandriva предписывает использовать вместо них дефисы.
Необязательно указывать в пути полное название страницы: его можно и по возможности следует сокращать.

Пути не могут содержать следующие символы:
- Пробелы (вместо них используйте дефисы)
- Точки (зарезервированы для расширений файлов)
- Небезопасные символы URL (например, знаки препинания, кавычки, математические символы и т. д.)

Поскольку нам часто приходится указывать номера версий выпусков (4.0, 4.1, 4.2 и т. д.), при создании новых страниц просто убирайте точку из номера версии в пути, используя `40`, `41`, `42` и т. д.

Если страница называется "*How to foo bar whatever*", её путь должен иметь вид `/doc/guides/howto-something`.
Не используйте `how-to`, `howtos`, `how-tos` и другие варианты.

### Процесс перевода
Для удобства организации сохраняйте исходный английский путь без изменений, заменяя только префикс кода языка. Например, `en/home` превратится в `fr/home`, `it/home` и т. д.
Другой пример: `/en/doc/guides/howto-list-packages-iso` превратится в `/it/doc/guides/howto-list-packages-iso`, а переведённый **заголовок страницы** (который отличается от пути) будет выглядеть так: "*Come ottenere una lista di tutti i pacchetti presenti nella ISO*"
Помните, что путь определяется соглашением об именовании, а заголовок страницы можно свободно переводить на свой язык.
Однако описанные выше действия упрощены и выполняются автоматически при нажатии на значок *Language* <i class="v-icon mdi mdi-web"></i> в правом верхнем углу страницы.
