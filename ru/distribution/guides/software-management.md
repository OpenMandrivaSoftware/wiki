# Программное обеспечение, предоставляемое OpenMandriva

## Для начинающих

* **Графический интерфейс**: OM Welcome
* **Использование графического интерфейса**: Discover
*Примечание: Discover хорошо справляется с задачей, отражённой в его названии: поиском ПО в репозиториях.
Не рекомендуется использовать его для обновления системы, а также установки и удаления пакетов.*
* **Графический интерфейс**: DNFDragora

## Для опытных пользователей
* **Командная строка**: [DNF](/en/distribution/guides/software-management/DNF)
* **Графический интерфейс**: [DnfDrake](/en/distribution/guides/software-management/DnfDrake)
