# Как получить список последних обновлений
Иногда обновления могут вызывать сбои в работе системы. В таких случаях при поиске причины проблемы полезно иметь под рукой список последних установленных обновлений.

Начнём с полного списка, из которого можно получить полезную информацию.

Основная команда:

```
rpm -qa --last
```

Она выводит список следующего вида:
.

    korganizer-17.12.2-1-omv2015.0.x86_64         Thu 15 Mar 2018 05:27:48 PM CET
    incidenceeditor-17.12.2-1-omv2015.0.x86_64    Thu 15 Mar 2018 05:27:48 PM CET
    lib64vdpau-drivers-17.3.6-1-omv2015.0.x86_64  Thu 15 Mar 2018 05:27:47 PM CET
    lib64korganizer_core5-17.12.2-1-omv2015.0.x86_64 Thu 15 Mar 2018 05:27:47 PM CET
    spectacle-17.12.2-1-omv2015.0.x86_64          Thu 15 Mar 2018 05:27:45 PM CET
    locales-en-2.27-9-omv2015.0.x86_64            Thu 15 Mar 2018 05:27:45 PM CET
    kdf-17.12.2-1-omv2015.0.x86_64                Thu 15 Mar 2018 05:27:44 PM CET
    task-plasma-5.10.5-4-omv2015.0.x86_64         Thu 15 Mar 2018 05:27:43 PM CET
    okular-tiff-17.12.2-1-omv2015.0.x86_64        Thu 15 Mar 2018 05:27:43 PM CET


Примечание: список может быть очень длинным, и некоторые строки могут не отображаться.
Чтобы просмотреть его полностью, упростить чтение или приложить к отчёту, полезно сохранить вывод консоли в текстовый файл.

_Пример_:
```
rpm -qa --last > rpmlast.txt
```
В вашем домашнем каталоге /home будет создан файл `rpmlast.txt`.

При каждом выполнении указанной выше команды можно задавать новое имя файла, чтобы сохранить предыдущий список и избежать его перезаписи.

_Пример_:
```
rpm -qa --last > rpmlast_20180315.txt
```

Список также можно сохранить в формате ".csv" (значения, разделённые запятыми), чтобы легко импортировать его в электронную таблицу,
_например Calc_:

```
rpm -qa --last> rpmlast_20180315.csv
```

Список может содержать множество строк, но его можно сократить, указав определённую дату.

_Пример_:
```
rpm -qa --last | grep Mar
``` 
Выводит обновления, установленные в марте. Чтобы узнать, как сокращённо обозначается нужный месяц, посмотрите список, созданный с помощью основной команды выше.

Вы также можете ограничить поиск определённым днём:

_Пример_:
```
rpm -qa --last | grep Thu\ 15\ Mar
```
