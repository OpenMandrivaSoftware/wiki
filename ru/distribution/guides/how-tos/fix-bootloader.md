# Как восстановить повреждённый загрузчик

OpenMandriva Lx использует загрузчик GRUB2, поэтому для его настройки применяются команды grub2.
Для обнаружения установленных операционных систем и создания полного меню загрузки GRUB2 используется следующая команда:
```
$ sudo grub2-mkconfig -o /boot/grub2/grub.cfg
```
В большинстве случаев достаточно выполнить следующую более простую команду:
```
$ sudo update-grub2
```
Затем, чтобы установить загрузчик GRUB2 на диск, с которого вы хотите загружать систему, выполните следующую команду:
```
$ sudo grub2-install /dev/xxx
```
Замените «*xxx*» именем диска, на который необходимо установить загрузчик или с которого ранее загружалась OMLx, например `sda` или, если используется NVMe-накопитель, `nvme0n1`.

Для выполнения этих действий вам потребуется доступ к установленной системе OMLx. Если обычным способом загрузить систему не удаётся, можно воспользоваться [Rescatux](https://sourceforge.net/p/rescatux/) или [Super Grub2 Disk](https://sourceforge.net/p/supergrub2/). Для решения этой задачи рекомендуем сначала попробовать Super Grub2 Disk.

Чтобы узнать имена накопителей и дисков в системе, достаточно открыть KDE Partition Manager или выполнить следующую команду в Konsole:
```
$ sudo fdisk -l
```
<br>

### Дополнительная информация:
Команды `grub2-mkconfig` и `update-grub2` используют утилиту ‘os-prober’ для поиска других ОС на компьютере.
Пользователь может запустить эту утилиту отдельно, чтобы проверить, правильно ли она обнаруживает все остальные ОС, установленные на компьютере. Для этого выполните следующую команду:
```
$ sudo os-prober
```
