# Как настроить принтер в OMLx
Включите принтер и проверьте, настроился ли он автоматически. Убедитесь, что установлен правильный драйвер.

Если принтер настроился автоматически и установлен правильный драйвер, всё готово к работе.

Если автоматическая настройка не произошла, выключите принтер.

Откройте *Настройки принтера* с помощью команды `kcmshell6 kcm_printer_manager` (если вы используете Plasma 5, укажите `kcmshell5` вместо `kcmshell6`) и удалите принтер из списка устройств.
Если нужный драйвер не был установлен по умолчанию, потребуется установить дополнительный пакет.

Следующим шагом нужно определить, какое ПО установить для вашего принтера.

В OpenMandriva Lx это, скорее всего, будет пакет 'task-printing', соответствующий производителю вашего принтера.
Доступны следующие пакеты:
- task-printing-canon
- task-printing-epson
- task-printing-hp
- task-printing-lexmark
- task-printing-okidata
- brlaser (для Brother принтеров)
- task-printing-misc

Установите пакет, соответствующий производителю вашего принтера. Если подходящего пакета нет, используйте пакет misc.

Пример для принтера Okidata:
```
$ sudo dnf install task-printing-okidata
```
Теперь вновь включите принтер, он должен автоматически настроиться (иногда для этого может потребоваться перезагрузка).

Если проблема сохраняется, обратитесь за помощью [сюда](https://forum.openmandriva.org/c/support/17).
