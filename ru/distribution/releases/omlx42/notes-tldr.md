# OMLx 4.2: краткое содержание примечаний

> **Рекомендуем ознакомиться с полной версией** [примечаний к выпуску OpenMandriva Lx 4.2](/releases/omlx42/notes), **а также со списком** [известных проблем OpenMandriva Lx 4.2](/releases/omlx42/errata) **в нашей вики.**
{.is-info}


## Доступные установочные образы
Этот выпуск доступен в виде Live-образа в формате ISO, который можно загрузить и записать на DVD или USB-накопитель (флешку).
*Live-образ* позволяет запустить OpenMandriva Lx непосредственно с DVD или USB-накопителя и опробовать систему перед установкой.

##  Рекомендуемые системные требования
Для работы OpenMandriva Lx требуется не менее 2048 МБ оперативной памяти и 10 ГБ свободного места на жёстком диске.

## Подключение к Интернету
Установщик Calamares проверяет наличие подключения к Интернету, однако OpenMandriva Lx успешно устанавливается и без него. Просто установите систему обычным способом и пользуйтесь ею без каких-либо ограничений, связанных с отсутствием подключения к Интернету.

## Виртуальные машины
В настоящее время ISO-образы OMLx тестируются только в VirtualBox. При запуске системы в виртуальной машине действуют те же требования к оборудованию.
Для работы в VirtualBox необходимо выделить не менее 2048 МБ оперативной памяти, иначе система не загрузится.

## Установщик и поддержка EFI
Этот выпуск OpenMandriva Lx поддерживает загрузку и установку как в режиме UEFI, так и без него.
Обратите внимание, что функция безопасной загрузки Secure Boot не поддерживается.

## Рекомендуемый тип файловой системы для ручной установки
Настоятельно рекомендуется использовать файловую систему ext4. Для накопителей на основе флеш-памяти также доступна файловая система F2FS.
Обратите внимание, что Calamares не может преобразовать один тип раздела в другой с сохранением данных.
При запуске Calamares из Live-образа изменить тип существующего раздела невозможно. Для этого необходимо сначала удалить раздел, а затем создать его заново, выбрав нужный тип.

## Загрузка с USB-накопителя
Для записи Live-образа или установочного образа можно использовать *rosa-imagewriter* или утилиту *dd*.
- rosa-imagewriter доступен в наших репозиториях
 `sudo dnf --refresh install rosa-imagewriter`
 или вы можете скачать его [здесь](http://wiki.rosalab.ru/en/index.php/ROSA_ImageWriter)

- В качестве альтернативы можно записать образ на USB-накопитель с помощью утилиты dd:
 `sudo dd if=<iso_name> of=<usb_drive> bs=4M`
 Замените `<iso_name>` путём к ISO-образу, а `<usb_drive>` именем устройства, соответствующего USB-накопителю, например `/dev/sdb`.

*SUSE Studio ImageWriter также был протестирован и успешно работает для записи ISO-образов на USB-накопители.*

> Пожалуйста, не используйте другие утилиты для записи образов на USB-накопители, поскольку некоторые программы для Windows (например, Rufus) обрезают имя тома. Это нарушает процесс загрузки системы.
{.is-danger}

## Репозитории OpenMandriva и доступное программное обеспечение
**В установленных системах OMLx по умолчанию включён только репозиторий /main.**
Для доступа к максимально широкому выбору программного обеспечения необходимо включить дополнительные репозитории: *unsupported*, *restricted* и *non-free*.
Используйте графическую утилиту [Software Repository Selector](https://wiki.openmandriva.org/en/doc/repositories-tldr) (om-repo-picker), чтобы включать или отключать нужные репозитории.

Хотя графические инструменты (Discover, dnfdragora и другие) удобны для поиска доступного программного обеспечения, мы настоятельно рекомендуем устанавливать пакеты через командную строку
 `sudo dnf --refresh install <package_name>`

## Известные проблемы и ошибки
-- **Видеокарты NVIDIA**
Этот выпуск включает драйвер nouveau, разработанный методом обратной инженерии.
Пользователи могут устанавливать драйверы с официального сайта NVIDIA, однако OpenMandriva не предоставляет их поддержку. Установка и сопровождение любых проприетарных драйверов осуществляются исключительно по усмотрению пользователя и под его ответственность.

-- **NVMe SSD**
Некоторые NVMe SSD могут не распознаваться при загрузке с Live ISO-образа OMLx 4.2.
Для Live ISO-образа предусмотрены 2 обходных решения. Подробнее см. в разделе [4.2/Errata#NVME SSDs](https://wiki.openmandriva.org/en/releases/omlx42/errata#nvme-ssds).

-- **GEOIP**
Автоматическое определение часового пояса по GEOIP в установщике может работать некорректно.

-- **Как настроить принтер**
Если принтер не был настроен автоматически, в OMLx доступны специальные пакеты 'task-printing' для различных производителей принтеров.
Установите пакет, соответствующий производителю вашего принтера. Если подходящего пакета нет, используйте пакет для прочих моделей.
