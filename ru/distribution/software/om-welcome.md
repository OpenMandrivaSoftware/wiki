# OpenMandriva Welcome

> Обратите внимание: OM-Welcome — **не просто** обычный экран *«Добро пожаловать в дистрибутив»*.
> OM-Welcome — многофункциональный инструмент первоначальной настройки и конфигурации, специально разработанный для рабочего окружения KDE Plasma в OpenMandriva.
{.is-success}

<br>

*Немного истории:
Начиная с OpenMandriva Lx 2014, при первом запуске системы пользователя встречает OM Welcome — программа, предназначенная для знакомства с дистрибутивом и его возможностями, помощи в настройке системы, а также установке различных приложений и утилит.*
<br>

OM Welcome будет открываться при каждой загрузке системы, пока пользователь не отключит его автоматический запуск.
<br>

### Добро пожаловать

![omlx60.doc.omwelcome-01.jpg](/images/omlx60.doc.omwelcome-01.jpg)

Первый экран знакомит пользователя с дистрибутивом, нашим сообществом и ценностями, на которых оно основано.
Все разделы приложения доступны по прямым ссылкам на верхней панели.
В нижней части экрана пользователь может отключить автоматический запуск OM Welcome при загрузке системы.

Рассмотрим различные разделы приложения, каждый из которых предназначен для решения определённых задач.

Нажмите <kbd>Next</kbd>, чтобы начать.
<br>
