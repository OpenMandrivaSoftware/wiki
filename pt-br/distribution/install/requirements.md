# Configuração mínima

O objetivo do OpenMandriva Lx é aproveitar o hardware mais recente, portanto, você não deve considerá-lo como uma solução para

Se você planeja instalar o OpenMandriva Lx em um PC comum, é necessário certificar-se de que o processador é de 64 bits (também chamado de x86_64), pois ele não funcionará em processadores que suportam apenas 32 bits (também chamados de x586). Se tiver alguma dúvida, saiba que a Intel deixou de produzir processadores exclusivamente de 32 bits em 2011. Portanto, qualquer PC recente deve ter um processador de 64 bits

Você precisa de pelo menos 2 GB de memória para executar o ambiente de desktop Plasma (o ambiente de desktop padrão do KDE) e a maioria dos aplicativos padrão (navegador, processamento de texto, reprodução de música etc.). No entanto, observe que a maioria dos jogos e até mesmo alguns sites podem exigir muito mais recursos para funcionar de forma adequada.

Considere usar uma unidade SSD em vez de discos rígidos mecânicos tradicionais para o sistema (você ainda pode transformar discos mecânicos em discos externos usando um dispositivo apropriado)

Você também precisa de 125 GB de espaço em disco para executar o OpenMandriva sem ter problemas de espaço no futuro.

# Configuração recomendada

Embora o Linux geralmente precise de muito menos recursos do que o Windows e o MacOS X para funcionar corretamente, outros softwares podem exigir a mesma quantidade de recursos, independentemente de serem executados no Linux ou não.

Portanto, o mais fácil é escolher o hardware de acordo com os requisitos dos softwares que você deseja utilizar.

Atualmente (segunda metade de 2021), podemos considerar confortável ter pelo menos 8 GB de RAM.
