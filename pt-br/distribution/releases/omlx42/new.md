# Novidades do OpenMandriva Lx 4.2

Recomendamos que leia as últimas [Notas de Lançamento](/distribution/releases/omlx42/notes) em nossa wikii.

## O que há de novo no OpenMandriva Lx 4.2?
OpenMandriva Lx 4.2 é um lançamento novo da OpenMandriva Association. [Codename](/policies/codename) Argon.

## Principais funcionalidades

### KDE

- Frameworks 5.78.0 [*(Mais informações)*](https://www.kde.org/announcements/kde-frameworks-5.78.0.php)
- Plasma 5.20.5 [*(Mais informações)*](https://www.kde.org/announcements/plasma-5.20.5.php)
- Applications 20.12.2 [*(Mais informações)*](https://kde.org/announcements/fulllog_releases-20.12.2/)
- Qt 5.15.2 [*(Mais informações)*](https://www.qt.io)

### Subsistema gráfico

- Xorg 1.20.10
- Wayland 1.20.10 [*(Mais informações)*](https://wayland.freedesktop.org/releases.html)
- Mesa 20.3 [*(Mais informações)*](http://www.mesa3d.org/)

### Núcleo

- Kernel 5.10.14 [*(Mais informações)*](https://www.kernel.org/)
- systemd 247 [*(Mais informações)*](https://www.freedesktop.org/wiki/Software/systemd/)
- LLVM/clang 11.0.1 [*(Mais informações)*](http://llvm.org/)
- binutils 2.36.1
- gcc 10.2 [*(Mais informações)*](https://gcc.gnu.org/)
- glibc 2.33 [*(Mais informações)*](http://www.gnu.org/software/libc/)
- Java 15
- Zstandard - é um novo algoritimo de compressão em tempo real, provê uma alta taxa de compressão implementada em nosso kernel, tornando a inicialização mais rápida.

A OpenMandriva disponibiliza um kernel compilado em clang. Os usuários podem instalar a mesma versão do pacote `kernel-release-desktop` e `kernel-release-desktop-clang` para comparação.

### Instalador

- Calamares 3.2.35 [*(Mais informações)*](https://calamares.io)

### Aplicativos

- LibreOffice 7.1.0
- Falkon 3.1
- Firefox 85
- Navegador Chromium estável 88 (and beta 89, dev 90)
- Krita 4.4.2
- Gimp 2.10.22
- Calligra Suite 3.2.1
- Digikam 7.2
- SMPlayer 21.1.0
- VLC 3.0.12
- Virtualbox 6.1.16
- OBS Studio 26.1.2

O port para aarch64 (processadores ARM de 64 bits) foi concluída, possibilitando a utilização de [substitutos de PCs por outros com eficiência energética por menos de US$ 150](https://videos.openmandriva.org/videos/watch/4e135a39-4232-4d85-999c-e349ba8a7bd9).
Imagens instaláveis ​​estão disponíveis para o PinebookPro, Raspberry Pi 4B e 3B+, Rock Pi 4A, 4B e 4C, Synquacer, Cubox Pulse e dispositivos genéricos compatíveis com UEFI, como a maioria das placas de servidor aarch64. Mais suporte para hardware aarch64 será adicionado em breve. Esta portabilidade também nos permite almelar smartphones pela primeira vez - uma imagem rodando no PinePhone está disponível (mas ainda não deve ser considerada de qualidade final).
