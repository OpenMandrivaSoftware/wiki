# Novidades do OpenMandriva Lx 4.3

Recomendamos que leia as últimas [Notas de Lançamento](/distribution/releases/omlx43/notes) em nossa wikii.

## O que há de novo no OpenMandriva Lx 4.3?
OpenMandriva Lx 4.3 é o novo lançamento da OpenMandriva Association. [Codinome] (/en/policies/codename) Dysprosium.

## Principais funcionalidades

### KDE

- Frameworks 5.90.0 [*(mais informações)*](https://kde.org/announcements/frameworks/5/5.90.0/)
- Plasma 5.23.5 [*(mais informações)*](https://kde.org/announcements/plasma/5/5.23.5/)
- KDE Gear 21.12.2 [*(mains informações)*](https://kde.org/announcements/gear/21.12.1/)
- Qt 5.15.3 [*(mais informações)*](https://www.qt.io)

### Subsistema gráfico

- Xorg 21.1.3
- Wayland 1.20.0 [*(mais informações)*](https://wayland.freedesktop.org/releases.html)
- Mesa 21.3.5 [*(mais informações)*](http://www.mesa3d.org/)

### Núcleo

- Kernel 5.16.7 [*(mais informações)*](https://www.kernel.org/)
- systemd 249 [*(mais informações)*](https://www.freedesktop.org/wiki/Software/systemd/)
- LLVM/clang 13.0.0 [*(mais informações)*](http://llvm.org/)
- binutils 2.37
- gcc 11.2 [*(mais informações)*](https://gcc.gnu.org/)
- glibc 2.34 [*(mais informações)*](http://www.gnu.org/software/libc/)
- Java 17
- Zstandard - ẽ um novo algoritimo de compressão em tempo real, provê uma alta taxa de compressão implementada em nosso kernel, tornando a inicialização mais rápida.

A OpenMandriva disponibiliza um kernel compilado em clang. Os usuários podem instalar a mesma versão do pacote `kernel-release-desktop` e `kernel-release-desktop-clang` para comparação.

### Instalador

- Calamares 3.2.39 [*(mais informações)*](https://calamares.io)

### Aplicativos

- LibreOffice 7.3.0
- Falkon 3.2
- Firefox 96
- Chromium browser stable 97 (and beta 98, dev 99)
- Krita 5.0.2
- Gimp 2.10.30
- Calligra Suite 3.2.1
- Digikam 7.5
- SMPlayer 21.10.0
- VLC 3.0.16
- Virtualbox 6.1.32
- OBS Studio 27.1.3

O port para aarch64 (processadores ARM de 64 bits) foi concluída, possibilitando a utilização de [substitutos de PCs por outros com eficiência energética por menos de US$ 150](https://videos.openmandriva.org/videos/watch/4e135a39-4232-4d85-999c-e349ba8a7bd9).
Imagens instaláveis ​​estão disponíveis para o PinebookPro, Raspberry Pi 4B e 3B+, Rock Pi 4A, 4B e 4C, Synquacer, Cubox Pulse e dispositivos genéricos compatíveis com UEFI, como a maioria das placas de servidor aarch64. Mais suporte para hardware aarch64 será adicionado em breve. Esta portabilidade também nos permite almelar smartphones pela primeira vez - uma imagem rodando no PinePhone está disponível (mas ainda não deve ser considerada de qualidade final).
